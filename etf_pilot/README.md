# 跨境 ETF 决策辅助仪表盘

基于 Python + Streamlit + AkShare 的**跨境 ETF 每日操作指导**工具：不负责自动交易，仅提供行情透视、偏离度预警与明日操作建议。

---

## 功能概览

- **决策看板**  
  - **行情透视**：40 只 ETF 距离「一年内最高点」和「一年内最低点」的百分比，定位当前价格空间。  
  - **偏离度预警**：相对 MA20、MA60、MA200 的乖离率（Bias）。  
  - **明日建议**：按「每日操作建议算法」给出「分批吸纳 / 持有观望 / 套利离场」及理由。  
  - 表格按**建议操作频率**排序，点击选择 ETF 可查看**明日操作卡片**（明天建议 + 理由）。

- **实时雷达**  
  精简一览：行情透视、偏离度、明日建议、建议操作频率、溢价率、信号准确率。

- **个股深度分析**  
  选择单只 ETF，查看 K 线、均线、布林带与成交量。

- **信号准确率**  
  过去 30 天若按「明日建议」操作，统计 3 日后收益是否与建议一致（分批吸纳且 3 日后涨、套利离场且 3 日后跌为正确）。

- **独家视角**  
  - **溢价率**：QDII ETF 估算溢价率（若接口支持则显示，避免高溢价接盘）。  
  - **极端风险模拟**：侧栏输入当前账户/持仓市值，显示「若标的发生 15% 回撤后」的金额。

---

## 每日操作建议算法（Action Logic）

- **[买入补仓] 分批吸纳**  
  当价格回落至 **MA60 附近**（上下约 2%）且 **RSI < 45** 时，标记为「分批吸纳」。

- **[持有观望]**  
  当价格在均线之上平稳运行，且无 MA60 吸纳区或布林上轨极值信号时，标记为「持有观望」。

- **[套利卖出] 套利离场**  
  当价格**触及布林带上轨**时，标记为「套利离场」。（若网格利润覆盖 5 倍手续费更佳，本仪表盘以触及上轨为主要条件。）

## 环境与安装

- **Python 3.9+**
- 依赖见 `requirements.txt`

```bash
cd etf_pilot
pip install -r requirements.txt
```

---

## 配置 ETF 列表

将 ETF 列表放到 **`data/ETF汇总.xlsx`**，需包含列：

- **代码**：ETF 代码（如 513100、518880）
- **名称**：ETF 名称
- **指数简称**（可选）：用于类别筛选

若未放置该文件，首次运行会在 `data` 目录下生成示例 Excel。

---

## 运行

```bash
streamlit run main.py
```
